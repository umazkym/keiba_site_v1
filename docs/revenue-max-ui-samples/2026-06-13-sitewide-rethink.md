# UMA-FREE 収益最大化UI 再考案

作成日: 2026-06-13

前回のモックをベースに、文言・トンマナ・他ページ展開を再整理した案です。基本方針は「広告を増やす」ではなく、「ユーザーが自然に確認を続ける導線を作り、結果として広告接触と回遊を増やす」です。

## 共通トンマナ

使う言葉:

- 確認する
- 判断材料
- 評価
- 評価を上げたい条件
- 評価を下げたい条件
- オッズ妙味
- ネット投票
- 関連データ
- 分析記事
- 本日の分析

避ける言葉:

- 投資
- 必勝
- 絶対
- 最強
- 精度の高い予想
- 消し
- 穴馬発見
- 買えばよい
- 最高価値
- 楽天ポイントで馬券購入できます

表記ルール:

- CTAは `見る` より `確認する` を基本にする。
- 広告・アフィリエイトは必ず `PR / スポンサー` を見える位置に置く。
- 楽天競馬など投票系は、地方競馬文脈に限定する。
- JRAページでは投票系CTAを出さず、AdSenseまたは物販系PRにする。
- 「本命」「対抗」は競馬メディアとして許容。ただし「必勝」「軸の筆頭」のような断定強化は避ける。

### 広告方針

- ヒーロー直下の大型広告は置かない。
- 本日の開催後に横長広告を1枠置く。
- 高配当ランキング後に300x250を置く。
- 記事一覧4枚目のネイティブ広告は維持。
- FAQ前後に大型広告を1枠置く。
- 追従広告はスクロール15%以降で表示し、ランキングやCTAに重ならないよう下余白を確保する。

## 記事一覧

### 現状評価

すでに `featured article → 広告 → 記事一覧 → 途中広告 → MultiplexAd` の骨格があるため、大きく壊す必要はない。

### 改善案

- ページ見出しを `記事` から `競馬データ分析記事` に寄せる。
- カテゴリチップに色を持たせる。ただし派手にしすぎず、背景色は淡くする。
- Featured記事の下に「この記事で確認できること」を2つだけ表示する。
- 記事カードに読了時間を常時表示する。
- 一覧の4枚目付近にネイティブ広告を入れる場合は、記事カードと同じ高さにそろえる。

### 文言案

| 箇所 | 現在 | 再考後 |
| --- | --- | --- |
| H1 | 記事 | 競馬データ分析記事 |
| リード | なし | 重賞・騎手・コース・馬場傾向を、レース前の判断材料として確認できます。 |
| Featured CTA | 読む | 記事を確認する |
| カテゴリ | すべて | すべての記事 |
| 空表示 | 該当する記事がありません | 条件に合う記事が見つかりませんでした |

### 広告方針

- Featured直後の広告は維持。
- 記事4件目または5件目の間にインフィード広告。
- 最下部のMultiplexAdは維持。ただしスマホでは記事一覧の余韻を潰さないよう、関連記事/FAQ導線の後でもよい。

## 記事詳細

### 現状評価

記事詳細は、本文前の検索導線・記事中広告・記事下PRがすでにあり、収益導線は強い。改善余地は「読み始めの圧迫感」と「広告が本文に割り込む見え方」。

### 改善案

- アイキャッチは現状維持。ただしスマホでは高さをさらに抑える。
- 目次見出しを `本文の流れを見る` から `この記事で確認できること` に変更する。
- `ArticleSearchEntryPanel` は記事冒頭ではなく、リード後の小型導線にする。本文開始前の圧迫を下げる。
- 記事内広告はH2直後ではなく、H2セクションを1つ読み終えた位置に寄せる。
- 記事末尾のAffiliateSlotは維持。物販中心にし、投票系は記事テーマが地方競馬のときだけに限定する。

### 文言案

| 箇所 | 現在 | 再考後 |
| --- | --- | --- |
| 目次 | 本文の流れを見る | この記事で確認できること |
| レース導線 | 本日の分析を見る | 本日のレース分析を確認する |
| カテゴリ導線 | ○○の記事をもっと見る | ○○の分析記事をもっと見る |
| 記事一覧導線 | 記事一覧へ | ほかの記事を確認する |
| 本文後広告前 | なし | スポンサーリンク |

### 広告方針

- 記事タイトル直後には置かない。
- リード・目次・導線を読んだ後に1枠。
- 本文中は1〜2枠まで。3,000〜4,000字の記事なら2枠が上限目安。
- 記事本文直後にAffiliateSlot、その後に関連記事、さらに下にAdSense/MultiplexAd。

## 検索ページ

### 改善案

検索ページは広告よりも回遊入口。検索直後の広告は結果閲覧の邪魔になりやすいため、結果一覧の後に置く現状方針はよい。

### 文言案

| 箇所 | 現在 | 再考後 |
| --- | --- | --- |
| H1 | サイト内検索 | UMA-FREE内を検索 |
| placeholder | キーワードを入力してください... | レース名・競馬場・騎手・コースで検索 |
| 初期説明 | サイト内の記事やページを検索できます。 | 気になるレース名や競馬場名から、関連データや分析記事を探せます。 |
| 結果数 | 20件の検索結果が見つかりました | 関連するページが20件見つかりました |
| 結果なし | 別のキーワードで検索してみてください。 | レース名、競馬場名、騎手名など別の語句でお試しください。 |

### 広告方針

- 検索フォーム直下には置かない。
- 検索結果一覧の後に1枠。
- 結果が0件のときは広告よりも「本日の分析」「記事一覧」への導線を優先。

## FAQ

### 現状評価

上部広告がブレッドクラム直下にあるため、質問に到達する前に広告が出る。FAQは信頼補強ページなので、上部広告は弱めたい。

### 改善案

- 上部広告を廃止または小さめにする。
- H1直下に「無料・更新・データの見方」を3チップで出す。
- FAQをカテゴリ分けする。
- FAQ末尾に本日の分析/記事一覧への導線を追加し、その後に広告を置く。

### 文言案

| 箇所 | 現在 | 再考後 |
| --- | --- | --- |
| H1 | よくある質問 | よくある質問 |
| リード | なし | UMA-FREEの使い方、更新タイミング、データの見方をまとめています。 |
| CTA | なし | 本日の分析を確認する / 分析記事を見る |

## コース別データ

### 現状評価

`robots: index false` なので、検索流入ページというより内部回遊・補助資料。広告を増やすより、レースページと記事詳細へ戻す役割を明確にする。

### 改善案

- H1下に「枠順」「脚質」「馬場」の3つの確認ポイントをチップ化。
- コースカードに「当日レースで確認する」導線を追加。
- 詳細ページでは「このコースの今日の該当レース」を表示できると強い。
- 広告は詳細ページの中盤または末尾に1枠まで。

### 文言案

| 箇所 | 現在 | 再考後 |
| --- | --- | --- |
| H1 | 競馬場・コース別データ分析 | コース別データ分析 |
| CTA | 本日の分析を見る | 今日の該当レースを確認する |
| セクション | 当日のレースに活かす | 今日のレースで確認する |

## 騎手別データ

### 現状評価

文言に `買いたい条件` があるが、サイト全体の文体ガードに合わせるなら `評価を上げたい条件` がよい。

### 改善案

- `買いたい条件` → `評価を上げたい条件`
- `割り引く条件` → `評価を下げたい条件`
- 騎手詳細末尾に「今日の騎乗レース」導線があると回遊に効く。
- 広告は末尾1枠まで。データの途中には入れない。

### 文言案

| 箇所 | 現在 | 再考後 |
| --- | --- | --- |
| H1 | 騎手別 得意コースデータ | 騎手別データ |
| 買いたい条件 | 買いたい条件 | 評価を上げたい条件 |
| 割り引く条件 | 割り引く条件 | 評価を下げたい条件 |
| CTA | 本日の分析を見る | 今日の騎乗レースを確認する |

## 運営者情報・広告について

### 方針

この2ページは収益枠を増やさない。AdSense審査・ユーザー信頼・透明性のためのページなので、広告収益より信頼性を優先する。

### 改善案

- 運営者情報ページは今のまま広告なしでよい。
- 「投票の助言や推奨は行っていません」は維持。
- 広告についてページは、実際の広告配置方針を反映し、PR表記・アフィリエイトリンクの区別を明記する。
- 広告ページ内の番号ズレ（`5. ユーザーのプライバシー保護` の中に `4.1` など）は修正候補。

## 実装優先度

1. レース詳細: 表上ナビ、凡例、位置取りバッジ、広告の読了直後化。
2. ホーム: 最近確認したレースの上部強化、ヒーロー文言具体化、本日の開催チップ情報追加。
3. 騎手ページ: `買いたい条件` 系の文言修正。
4. 記事一覧: H1/リード/カテゴリ色分け/カード読了時間の整理。
5. 記事詳細: 目次名と本文前導線の自然化、広告位置の微調整。
6. FAQ: 上部広告の弱体化、FAQ末尾導線強化。
7. コース/騎手詳細: 今日の該当レース導線追加。
