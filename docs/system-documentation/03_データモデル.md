### 3.3.8 horse_number_advantages (枠番有利度)

**用途**: 各コース・距離における馬番ごとの統計的有利度を格納

**ファイル**: `backend/database/models/horse_number_advantage.py`

| カラム名 | 型 | NULL | 説明 |
|---------|-----|------|------|
| id | Integer | NO | プライマリキー (自動採番) |
| venue_name | String(50) | NO | 競馬場名 |
| course_type | String(10) | NO | `芝` または `ダート` |
| distance | Integer | NO | 距離 (メートル) |
| horse_number | Integer | NO | 馬番 |
| advantage_score | Float | NO | 有利度スコア (-100 〜 +100) |

**制約**:
- UNIQUE: `(venue_name, course_type, distance, horse_number)`

**インデックス**:
- PRIMARY KEY: `id`
- UNIQUE INDEX: `(venue_name, course_type, distance, horse_number)`

**advantage_score 計算方法**:
```python
# 実績連対率 - 期待連対率
expected_rate = 2.0 / total_horses  # 2着以内の期待値
actual_rate = top2_count / total_races
advantage_score = (actual_rate - expected_rate) * 100

# 例: 18頭立てで馬番1の連対率が20%の場合
# expected = 2/18 = 11.1%
# actual = 20%
# advantage_score = (0.20 - 0.111) * 100 = +8.9
```

## 3.5 SQLAlchemy モデル実装例

### 3.5.1 Race モデル

# backend/database/models/race.py
from sqlalchemy import Column, String, Integer, Date, DateTime
from sqlalchemy.orm import relationship
from backend.database.base import Base
from datetime import datetime

class Race(Base):
    __tablename__ = "races"

    id = Column(String(50), primary_key=True)
    race_date = Column(Date, nullable=False, index=True)
    venue_name = Column(String(50), nullable=False, index=True)
    race_number = Column(Integer, nullable=False)
    race_name = Column(String(100))
    race_type = Column(String(10), nullable=False)  # JRA or NAR
    course_type = Column(String(10))  # 芝 or ダート
    distance = Column(Integer)
    weather = Column(String(20))
    ground_condition = Column(String(20))
    total_horses = Column(Integer)
    created_at = Column(DateTime, default=datetime.utcnow)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

    # リレーションシップ
    results = relationship("Result", back_populates="race", cascade="all, delete-orphan")
    predictions = relationship("Prediction", back_populates="race", cascade="all, delete-orphan")
    matchups = relationship("Matchup", back_populates="race", cascade="all, delete-orphan")
    returns = relationship("RaceReturn", back_populates="race", cascade="all, delete-orphan")

## 3.6 データ整合性とバリデーション

### 3.6.1 制約による整合性保証

1. **PRIMARY KEY**: 各テーブルで一意性保証
2. **FOREIGN KEY**: 参照整合性保証
3. **UNIQUE制約**: 重複防止
4. **NOT NULL制約**: 必須項目の保証

### 3.6.2 アプリケーションレベルの検証

```python
# Pydanticスキーマでの検証例
from pydantic import BaseModel, Field, validator

class PredictionCreate(BaseModel):
    race_id: str = Field(..., max_length=50)
    horse_id: str | None = Field(None, max_length=20)
    horse_name: str = Field(..., max_length=100)
    horse_number: int = Field(..., ge=1, le=18)
    deviation_score: float | None = Field(None, ge=0, le=100)

    @validator('deviation_score')
    def validate_deviation(cls, v):
        if v is not None and (v < 0 or v > 100):
            raise ValueError('偏差値は0〜100の範囲である必要があります')
        return v
```

### 3.6.3 トランザクション管理

```python
from sqlalchemy.orm import Session
from contextlib import contextmanager

@contextmanager
def get_db_session():
    db = SessionLocal()
    try:
        yield db
        db.commit()
    except Exception:
        db.rollback()
        raise
    finally:
        db.close()

# 使用例
with get_db_session() as db:
    race = Race(id="202501150106", race_date="2025-01-15", ...)
    db.add(race)
    # commitは自動的に実行される
```

## 3.8 パフォーマンス最適化

### 3.8.1 インデックス戦略

**頻繁に検索されるカラム**:
- `races.race_date`: 日付範囲検索
- `races.venue_name`: 競馬場フィルタ
- `results.race_id`: JOIN操作
- `results.horse_id`: 馬の過去成績検索

### 3.8.2 クエリ最適化

**Eager Loading (N+1問題の回避)**:
```python
# 悪い例 (N+1問題)
races = db.query(Race).all()
for race in races:
    for result in race.results:  # 各レースでクエリ発行
        print(result.horse.name)  # 各結果でクエリ発行

# 良い例 (Eager Loading)
from sqlalchemy.orm import joinedload

races = db.query(Race).options(
    joinedload(Race.results).joinedload(Result.horse)
).all()

for race in races:
    for result in race.results:
        print(result.horse.name)  # クエリ発行なし
```
