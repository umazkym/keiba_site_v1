## 8.1 デプロイメント概要

## 8.2 Google Cloud Run デプロイ設定

### 8.2.1 サービス情報

| 項目 | 値 |
|:---|:---|
| サービス名 | `keiba-site-v1` |
| リージョン | `us-west1` |
| プロジェクト | `keiba-api-project` |
| VPCネットワーク | `default` |
| VPC Egress | `private-ranges-only` |

### 8.2.2 環境変数設定

**Cloud Runサービスで設定**:

```bash
# データベース (GCE VM 内部IP経由)
DATABASE_URL=postgresql://keiba_user:***@10.138.0.2:5432/keiba_db

# その他
TZ=Asia/Tokyo
```

### 8.2.3 デプロイ手順

1. **自動デプロイ**:
   GitHubの`main`ブランチへのPushと連動して、Cloud Buildが自動的にコンテナイメージをビルドし、Cloud Runにデプロイします。手動での反映は通常不要です。

2. **手動デプロイ** (必要な場合):
   ```bash
   gcloud run deploy keiba-site-v1 \
     --project=keiba-api-project \
     --region=us-west1 \
     --source=.
   ```

3. **ログ確認**:
   ```bash
   gcloud run services logs read keiba-site-v1 \
     --project=keiba-api-project \
     --region=us-west1 \
     --limit=20
   ```

### 8.2.4 Cloud Run ↔ GCE VPC接続

Cloud RunからGCE VMのPostgreSQLへは**VPC内部IP (10.138.0.2)** で通信します。

```bash
# VPC Egress設定の確認
gcloud run services describe keiba-site-v1 \
  --project=keiba-api-project \
  --region=us-west1 \
  --format="value(spec.template.metadata.annotations['run.googleapis.com/vpc-access-egress'])"
```

## 8.3 GCE VM (PostgreSQL) 管理

### 8.3.1 VM情報

| 項目 | 値 |
|:---|:---|
| インスタンス名 | `keiba-db` |
| マシンタイプ | `e2-micro` (永久無料枠) |
| ゾーン | `us-west1-b` |
| 内部IP | `10.138.0.2` |
| 外部IP | `34.182.6.97` (静的) |
| OS | Debian |
| PostgreSQL | 15 |

### 8.3.2 SSH接続

```bash
gcloud compute ssh keiba-db --zone=us-west1-b --project=keiba-api-project
```

### 8.3.3 PostgreSQL管理コマンド

```bash
# SSH接続後
sudo -u postgres psql keiba_db

# テーブル一覧
\dt

# レース数確認
SELECT COUNT(*) FROM races;

# PostgreSQLサービス管理
sudo systemctl status postgresql
sudo systemctl restart postgresql
```

### 8.3.4 ファイアウォール設定

```bash
# 現在のルール確認
gcloud compute firewall-rules list --project=keiba-api-project

# PostgreSQLポート (tcp:5432) が許可されていることを確認
gcloud compute firewall-rules describe allow-postgres --project=keiba-api-project
```

### 8.3.5 PostgreSQL設定ファイル

```bash
# postgresql.conf の主要設定
shared_buffers = 256MB
max_connections = 50
listen_addresses = '*'

# pg_hba.conf の主要設定
# Cloud RunのVPCサブネット
host    keiba_db    keiba_user    10.0.0.0/8        md5
# GitHub Actions・ローカル開発
host    keiba_db    keiba_user    0.0.0.0/0         md5
```

## 8.6 バックアップ戦略

### 8.6.1 データベースバックアップ

**手動バックアップ**:
```bash
# GCE VMにSSH接続後
sudo -u postgres pg_dump keiba_db > backup_$(date +%Y%m%d).sql

# ローカルにダウンロード
gcloud compute scp keiba-db:~/backup_YYYYMMDD.sql . \
  --zone=us-west1-b --project=keiba-api-project
```

**将来の自動化** (推奨):
```bash
# GCE VM上にcronジョブを設定
0 3 * * 0 sudo -u postgres pg_dump keiba_db | gzip > /var/backups/keiba_db_$(date +\%Y\%m\%d).sql.gz
# 古いバックアップを自動削除 (30日以上)
0 4 * * 0 find /var/backups/ -name "keiba_db_*.sql.gz" -mtime +30 -delete
```

### 8.6.2 コードバックアップ

**GitHub**: 自動的にバージョン管理

**タグ付け**:
```bash
git tag -a v1.0.0 -m "Production release 1.0.0"
git push origin v1.0.0
```
