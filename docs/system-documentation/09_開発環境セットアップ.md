## 9.3 バックエンド開発環境

### 9.3.1 Python仮想環境のセットアップ

```bash
cd backend

# 仮想環境作成
python3 -m venv venv

# 仮想環境有効化 (macOS/Linux)
source venv/bin/activate

# 仮想環境有効化 (Windows)
venv\Scripts\activate

# 依存関係インストール
pip install -r requirements.txt
```

### 9.3.2 環境変数設定

**`.env` ファイル作成**:
```bash
cd backend
touch .env
```

**内容**:
```bash
# データベース (ローカルはSQLite)
DATABASE_URL=sqlite:///./keiba.db

# Twitter API (開発時は不要、テスト時のみ)
TWITTER_CONSUMER_KEY=your_api_key_here
TWITTER_CONSUMER_SECRET=your_api_secret_here
TWITTER_API_KEY=your_api_key_here
TWITTER_API_SECRET=your_api_secret_here
TWITTER_ACCESS_TOKEN=your_access_token_here
TWITTER_ACCESS_TOKEN_SECRET=your_access_token_secret_here

# Threads API (開発時は不要、テスト時のみ)
THREADS_USER_ID=your_threads_user_id_here
THREADS_ACCESS_TOKEN=your_threads_access_token_here
THREADS_TOKEN_EXPIRY=YYYY-MM-DD

# SNS投稿テスト
API_BASE_URL=http://localhost:8000
ENABLE_TWITTER=true
ENABLE_THREADS=true
FAIL_ON_SNS_ERROR=false
DRY_RUN=1

# バッチサイズ (ローカルは大きめでOK)
BATCH_SIZE=50
MAX_WORKERS=4
POOL_SIZE=10

# その他
PYTHON_VERSION=3.11
TZ=Asia/Tokyo
```

### 9.3.3 データベース初期化

```bash
# テーブル作成
python -c "from database.session import engine; from database.base import Base; Base.metadata.create_all(bind=engine)"

# または、Alembicでマイグレーション
alembic upgrade head
```

### 9.3.4 サーバー起動

```bash
cd backend

# 開発サーバー起動
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# または
python -m uvicorn main:app --reload
```

**アクセス**:
- API: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

### 9.3.5 テストデータ投入

**手動でのテスト**:
```bash
# 明日のレース予測を生成
python run_pipeline.py --mode PREDICTIONS_ONLY --target tomorrow

# 昨日の結果を取得
python run_pipeline.py --mode RESULTS_ONLY --target yesterday
```

**サンプルデータ投入スクリプト** (オプション):
```python
# scripts/seed_data.py
from database.session import SessionLocal
from database.models import Race, Horse, Jockey
from datetime import date

db = SessionLocal()

# サンプルレース
race = Race(
    id="202501150106",
    race_date=date(2025, 1, 15),
    venue_name="東京",
    race_number=6,
    race_name="東京新聞杯",
    race_type="JRA",
    course_type="芝",
    distance=1600,
    total_horses=16
)
db.add(race)

# サンプル馬
horse = Horse(
    id="2019105303",
    name="イクイノックス",
    sex="牡",
    age=5
)
db.add(horse)

db.commit()
db.close()

print("Sample data inserted!")
```

実行:
```bash
python scripts/seed_data.py
```

### 9.8.1 Chrome WebDriver設定

**自動インストール** (webdriver-managerが自動で行う):
```python
from selenium import webdriver
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service

service = Service(ChromeDriverManager().install())
driver = webdriver.Chrome(service=service)
```

### 9.8.2 ヘッドレスモード

**開発時はGUI表示**:
```python
options = webdriver.ChromeOptions()
# options.add_argument('--headless')  # コメントアウト

driver = webdriver.Chrome(options=options)
```

**本番時はヘッドレス**:
```python
options = webdriver.ChromeOptions()
options.add_argument('--headless')
options.add_argument('--no-sandbox')
options.add_argument('--disable-dev-shm-usage')

driver = webdriver.Chrome(options=options)
```

## 9.9 Git ワークフロー

### 9.9.1 ブランチ戦略

```bash
main          # 本番環境
  ├── develop # 開発環境
  │    ├── feature/new-feature    # 機能開発
  │    ├── bugfix/fix-prediction  # バグ修正
  │    └── hotfix/urgent-fix      # 緊急修正
```

### 9.9.2 開発フロー

```bash
# 1. 最新のmainを取得
git checkout main
git pull origin main

# 2. 新しいブランチを作成
git checkout -b feature/add-jockey-stats

# 3. 開発&コミット
git add .
git commit -m "Add jockey statistics calculation"

# 4. プッシュ
git push origin feature/add-jockey-stats

# 5. GitHubでPull Request作成

# 6. レビュー後、mainにマージ
```

## 9.10 トラブルシューティング

### 9.10.1 よくあるエラー

#### Python依存関係エラー
```bash
# エラー: ModuleNotFoundError: No module named 'fastapi'

# 解決策
cd backend
source venv/bin/activate
pip install -r requirements.txt
```

#### Next.jsビルドエラー
```bash
# エラー: Error: Cannot find module 'next'

# 解決策
cd frontend
rm -rf node_modules package-lock.json
npm install
```

#### データベース接続エラー
```bash
# エラー: OperationalError: unable to open database file

# 解決策
cd backend
python -c "from database.session import engine; from database.base import Base; Base.metadata.create_all(bind=engine)"
```

#### Selenium WebDriverエラー
```bash
# エラー: WebDriverException: chrome not reachable

# 解決策
# Chromeを最新版に更新
# webdriver-managerが自動で適切なドライバーをダウンロード
pip install --upgrade webdriver-manager
```

### 9.10.2 デバッグ方法

**Python (pdb)**:
```python
import pdb; pdb.set_trace()  # ブレークポイント
```

**VSCode デバッガー**:
1. `launch.json` に設定を追加
2. F5でデバッグ開始
3. ブレークポイント設定

**Next.js デバッグ**:
```typescript
console.log('Debug:', variable);

```

## 9.11 開発のベストプラクティス

### 9.11.1 コーディング規約

**Python (PEP 8)**:
```python
# 良い例
def calculate_deviation_score(performance_scores: List[float]) -> List[float]:
    """偏差値を計算する"""
    pass

# 悪い例
def calcDevScore(scores):
    pass
```

**TypeScript**:
```typescript
// 良い例
interface PredictionData {
  horseId: string;
  horseName: string;
  deviationScore: number;
}

// 悪い例
interface pred {
  id: string;
  name: string;
  score: number;
}
```

### 9.11.2 コミットメッセージ

**フォーマット**:
```
<type>: <subject>

<body>

<footer>
```

**例**:
```
feat: Add jockey statistics to prediction algorithm

- Calculate jockey win rate for each venue
- Add jockey_score field to Prediction model
- Update API response schema

Closes #42
```

**Type**:
- `feat`: 新機能
- `fix`: バグ修正
- `docs`: ドキュメント
- `style`: コードスタイル
- `refactor`: リファクタリング
- `test`: テスト
- `chore`: その他
