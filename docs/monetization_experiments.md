更新日: 2026-08-03

日付順の作業とユーザーが用意するものは、[`monetization_task_calendar_2026.md`](./monetization_task_calendar_2026.md)へ集約する。このファイルは実験条件、判断結果、復元方法の詳細台帳として扱う。

## 運用原則

- 主要KPIは「AdSense収益 / 1,000人間セッション」。2026年6月22日〜7月21日の暫定基準は約392円。
- 終了判断日の9:00 JSTにCodexリマインドが登録されていない実験は開始しない。
- リマインドは判断を促すだけとし、広告設定を自動終了・自動変更しない。
- 管理画面で同時対照群とランダム配分を確認できない公開施策はA/B実験と呼ばず、因果効果を判定しない。
- 同時対照群がない施策は、所定の安全観測日までに固定ベースライン化、元設定への復元、または別の対照実験への切り替えを決め、処置側の表示数だけを理由に延長し続けない。
- 原案とバリエーションのどちらを採用する場合も、終了操作と採用設定の反映を同時に行い、広告が無効な中間状態を作らない。
- 単日の推定収益では判断せず、前日までの確定値と同曜日構成を使う。

- 安全性: ポリシー問題、広範な未配信、解除不能、主要操作阻害の証拠なし。

- ポリシー警告、広範な未配信、解除不能なOfferwall、主要操作の阻害、重大なCLSやJavaScript障害はサンプルを待たずに原案へ戻す。
