## 7. 記事執筆・分析時の重要ルール（再整理）

コラム記事や重賞攻略記事を執筆する際、誇張表現やハルシネーションを防ぎ、AdSenseポリシーを厳守するための必須ルールです。

1.  **文体ガード・誇張表現の徹底排除**:
    *   以下の言葉は**一切使用禁止**（見出し・本文含む）。
        *   「投資」「必勝」「絶対」「確実」「最強」「圧倒的」「極限」「消去対象」「狙い撃つ」「買うな」「いかがでしたか」「ぜひ参考にしてください」
    *   代わりに以下の表現で代用すること。
        *   「判断材料」「評価を下げたい条件」「オッズ妙味」「相手候補」「慎重に見る条件」
2.  **ハルシネーション（数値の捏造）の禁止**:
    *   WriteOrderに記述されていない具体的な数値（勝率〇〇%、単勝回収率〇〇%など）を勝手に脳内で補完・生成してはならない。
    *   実績馬の戦績を推測で書くことは厳禁。データが存在しない場合は、マクロデータ（コース・枠順の全体傾向など）に徹底すること。
3.  **まとめ見出しの禁止**:
    *   記事末尾を「まとめ」や「総括」といった抽象的な見出しで締めてはならない。
    *   テーマクラスターに応じた固有の見出し（`## この競馬場の確認ポイント`など）で締め、読者が直感的に使える具体的な判断材料を箇条書きで提示すること。
4.  **外部リンクの埋め込み禁止**:
    *   記事本文内に外部サイトへの直接リンクを埋め込んではならない（ドメインエラー防止）。
