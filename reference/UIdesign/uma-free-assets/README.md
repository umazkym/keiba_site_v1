## 実装時にこちらで直すもの（作り直し不要）

- 芝の色：指定（色相 106〜121°）より黄緑寄り（中央値で 69〜80°）。冬以外の芝の写真は、緑の範囲だけ色相を +25° 前後、彩度を −10% に補正して書き出す（`grade-winter` は枯れ芝なので補正しない）。
- ゼッケンの読めない文字：`sns-turf`・`sns-night` の先頭の馬の鞍下に文字のような白い模様がある。動画では不透明度35%で敷くので見えないが、Instagram の表紙など全面で使うときは該当箇所をぼかす。
- ダートの色：色相は指定どおり（25〜29°）、彩度がやや低い。砂煙の灰色寄りとして許容し、補正しない。

## YouTubeバナー（2026-09-24 作り直し分から採用）

- `youtube-banner.png` ← Downloads の `ChatGPT Image 2026年9月24日 23_11_46.png`（1672×941）。
  - 馬群が横 33〜74%・縦 39〜65% にあり、全端末で見える中央の範囲（横 20〜80%・縦 35〜65%）に収まる。
  - 寸法は YouTube の最小 2048×1152 に足りないため、書き出し時に 2560×1440 へ拡大する（1.53倍）。芝は他と同じく緑へ補正する。
  - 馬群が中央を占めるので、ロゴと文字は中央に重ねない。
  - **決定（2026-09-25）**: バナーは写真だけ（`profile/youtube-banner-2560x1440.jpg`）。チャンネルのアイコンと名前が横に並ぶため、ロゴは載せない。左の帯にロゴを置いた案（`profile/youtube-banner-2560x1440-logo.jpg`）は不採用で、比較用に残している。
- プロフィール素材は `profile/`（書き出しは `.local/design-portfolio/impl/export_profile_assets.py`）。YouTubeバナー・Xのヘッダー（1500×500）・アイコン（800×800）。アップロードは手動。
