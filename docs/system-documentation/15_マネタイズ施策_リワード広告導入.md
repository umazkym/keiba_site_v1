# マネタイズ施策：AdSense オファーウォール（リワード広告）導入

本ドキュメントは、競馬予想サイトにおいて「過去対決成績」「このコースの枠順傾向」「詳細データ分析」などのプレミアムコンテンツを、Google AdSenseの「オファーウォール（Offerwall）」機能を活用して収益化する施策についてまとめたものです。

## 0. 2026-06-05時点の運用注記

現時点では、リワード広告ゲートは一時停止運用とする。GAMの対象広告ユニット `/23345285369/uma-free-rewarded-premium` は存在し、有効で、サイト側の広告ユニットパスとも一致している。ただし、GAM管理画面では過去7日間のインサイトがなく、今後30日間に配信予定の広告申込情報も表示されない。リワードの金額・タイプ・サーバーサイド認証ポストバックURLも空欄である。

そのため、在庫が安定するまで `NEXT_PUBLIC_REWARDED_AD_MODE` は未設定または `fallback` のままとし、詳細データはゲートで止めずに表示する。再開条件と確認手順は `docs/system-documentation/18_リワード広告運用チェックリスト.md` を参照する。

## 1. 結論：AdSense オファーウォールが最適な選択肢
前回の分析ではGoogle Ad Manager (GAM) を使った複雑な手動実装（ボタンごとの個別制御）を推奨しましたが、ベンチャー企業や少人数での開発・運用リソースを考慮した場合、**AdSenseが公式に提供している「オファーウォール」機能を利用することが圧倒的に費用対効果が高く、最強の選択肢**となります。

（※国内メディア『Green Cardニュース』などでも、離脱率を悪化させずに収益を74%向上させた成功事例として公式に紹介されています。）

## 2. AdSense オファーウォールの仕組みとメリット
*   **ノーコード導入**: サイト側で複雑なJavaScriptのコールバック制御（動画再生完了の検知やCSSの書き換え等）を実装する必要がありません。AdSenseの管理画面（[プライバシーとメッセージ] > [オファーウォール]）から設定するだけで自動的に稼働します。
*   **最適なUXの自動化**: 「リワード広告（短い動画）を見てコンテンツにアクセスする」という選択肢をユーザーに美しいUIで提示できます。

## 3. 競馬サイトでの具体的な導入UXパターン

オファーウォールは基本的に「ページ単位（URL単位）」または「PV数（メータリング）」で機能します。特定のデータ（コンポーネント）だけを隠したい場合、以下のサイト設計にすることで完璧に機能します。

### パターンA：プレミアムデータ専用URLを設ける（推奨）
「出馬表・基本情報」のページと、「詳細分析データ」のページをURLで分割します。
1.  **通常ページ (`/race/123`)**: 全員がすぐに見られる（出馬表、オッズなど）。
2.  **詳細ページ (`/race/123/premium` または `/race/123#data`)**: 過去対決成績、このコースの枠順傾向、データ分析などを配置。
*   **設定**: AdSenseオファーウォールの「URLの登録と除外」設定で、詳細ページ（例: `/premium` がつくURL）にのみオファーウォールが発動するようにターゲット設定します。
*   **ユーザー体験**: ユーザーが「データ分析を見る」ボタンを押して詳細ページに遷移すると、オファーウォール画面（「動画広告を見てコンテンツへアクセス」）が表示されます。

### パターンB：メータリング（PV数制限）での発動
特定のURLに固定せず、ユーザーが熱心にサイトを回遊し始めたタイミングで発動させます。
1.  **設定**: しきい値を例えば「3」に設定。
2.  **ユーザー体験**: ユーザーが3ページ目（例：3レース目のデータ分析）を見ようとした瞬間にオファーウォールが立ち上がり、「これ以降のデータを見るには広告を視聴してください」と促します。
熱心なユーザー（ロイヤルユーザー）から確実に収益を上げつつ、直帰してしまうライト層の離脱を防ぐことができます。

## 4. 実装手順の概要

1.  **コンテンツの整理**: 「誰でも見られる無料情報」と「広告を見てでも見たいプレミアム情報（過去対決成績、このコースの枠順傾向、データ分析）」への導線を整理する。
2.  **AdSense管理画面での設定**:
    *   AdSenseメニューの「プライバシーとメッセージ」>「オファーウォール」を開く。
    *   「オファーウォール メッセージを作成する」をクリック。
    *   ユーザーチョイスの設定で「リワード広告」をオンにする。
    *   表示ターゲット（特定のURLのみか、全ページのPV数ベースか）を設定する。
    *   メッセージの文言をカスタマイズ（例：「このレースの詳細データ・過去成績を見るには広告をご視聴ください」）。
3.  **公開と検証**:
    *   本番環境で実際にサイトを回遊し、意図したタイミングでオファーウォールが表示されるかテストする。
