### 8.2.3 デプロイ手順

1. **GitHubリポジトリ連携**:
   ```
   Render Dashboard → New → Blueprint
   → GitHub連携 → リポジトリ選択
   ```

2. **render.yaml自動検出**:
   Renderが自動的にrender.yamlを読み込み、サービスを作成

3. **環境変数設定**:
   各サービスの「Environment」タブで環境変数を設定

4. **手動デプロイ** (初回):
   ```
   Dashboard → keiba-backend → Manual Deploy
   ```

5. **自動デプロイ有効化**:
   GitHubのmainブランチへのpushで自動デプロイ

## 8.4 データベースマイグレーション

### 8.4.1 初回セットアップ

```bash
# ローカルでマイグレーションファイル生成
cd backend
alembic init alembic
alembic revision --autogenerate -m "Initial migration"

# Render環境で実行
# Renderシェルにアクセス
render shell keiba-backend

# マイグレーション実行
cd backend
alembic upgrade head
```

### 8.4.2 スキーマ変更時

```bash
# 1. ローカルでモデル変更
# backend/database/models/xxx.py を編集

# 2. マイグレーションファイル生成
alembic revision --autogenerate -m "Add new column"

# 3. コミット&プッシュ
git add .
git commit -m "Database schema update"
git push origin main

# 4. Render環境で実行
render shell keiba-backend
cd backend
alembic upgrade head
```

## 8.6 パフォーマンス最適化

### 8.6.1 バックエンド最適化

**Uvicorn設定**:
```bash
# render.yaml startCommand
uvicorn main:app \
  --host 0.0.0.0 \
  --port $PORT \
  --workers 1 \         # Renderのメモリ制約
  --timeout-keep-alive 75
```

**接続プール**:
```python
# backend/database/session.py
if os.getenv('RENDER'):
    engine = create_engine(
        DATABASE_URL,
        pool_size=3,           # 最小限
        max_overflow=0,        # オーバーフロー禁止
        pool_recycle=3600,     # 1時間ごとにリサイクル
        pool_pre_ping=True     # 接続チェック
    )
```

### 8.6.2 フロントエンド最適化

**ISR設定**:
```typescript
// app/races/[date]/page.tsx
export const revalidate = 300;  // 5分
```

**Static Params**:
```typescript
export async function generateStaticParams() {
  // 過去30日〜未来14日を事前生成
  const dates = [];
  for (let i = -30; i <= 14; i++) {
    dates.push({ date: format(addDays(new Date(), i), 'yyyy-MM-dd') });
  }
  return dates;
}
```
