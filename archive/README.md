# 過去の資料とローカル記録

ここは現行システムから参照しない資料の保管場所です。サイト・GitHub Actions・記事生成・SNS・YouTubeは、このディレクトリを実行時に読みません。

| 場所 | 内容 | 扱い |
| --- | --- | --- |
| `legacy-tools/` | 旧DB移行、固定日付の診断、Gemini接続試験、過去の記事一括修正 | 元の階層を保持。拡張子に`.txt`を付け、自動テストや誤実行から隔離 |
| `prototypes/` | 過去のHTML試作と生成スクリプト | 現行サイトの仕様ではない |
| `reports/` | 旧AdSense改善案、改稿ログ | 当時の経緯として参照 |
| `legacy-notes/` | 予測・DB接続ファイルの先頭に残っていた旧コードのコメント | 実行コードのAST一致を確認して分離 |
| `legacy-assets/` | 現行参照のない旧配置のロゴ・重複フォント | 現行の`backend/fonts/`と`frontend/public/`は維持 |
| `local/` | 取得HTML、画面スナップショット、ログ、CSV、個人レポート | この端末だけに保持。Git管理・本番配布の対象外 |
| [manifest.json](manifest.json) | 元の場所・移動先・理由・SHA-256 | 移動漏れと内容の保持を確認する台帳 |

アーカイブ判断は名称だけでなく、Workflow、package.json、Python import、コード中のファイル参照との照合に基づきます。現行の修復・migrationスクリプト、参照されるフォント、動画素材、記事レジストリは残しています。追加で整理した作業記録は`local/workspace-2026-09-07/`へ元の階層のまま保存しています。その移動先と現役ファイルの移設は[配置変更台帳](../docs/operations/layout-moves.json)で確認できます。

`.gitattributes`でこのディレクトリの改行自動変換を無効にし、別OSでcheckoutしても原本のSHA-256が一致するようにしています。

旧診断を再利用する場合は、台帳の元の作業ディレクトリ、import、固定日付、接続先、書き込み処理を先に確認してください。`.py.txt`をそのまま現行保守コマンドとして実行しません。必要な部分を現行ツールへ移し、テストしてから使います。

旧DB認証情報は保存時に伏字化し、ユーザーから失効・変更済みであることを確認しました。過去のGit履歴の書き換えは行っていません。`local/`は初回cloneには含まれません。内容の削除や自動期限切れは今回設定していません。

収益集計の受入テストは、保存した`local/workspace-2026-09-07/分析レポート/`を読み、過去の出力値を再現します。これはテスト用の読取であり、サイト運用や定期処理の入力には使いません。ローカル原本がないcloneでは従来どおり該当テストだけをスキップします。
