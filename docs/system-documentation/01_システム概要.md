# 01. システム概要

## 1.1 プロジェクト名

**UMA-FREE (keiba_site_v1)**

中央競馬(JRA)と地方競馬(NAR)のAI予測を提供する競馬情報サイト

---

## 1.2 プロジェクトの目的

本システムは、競馬ファンに対して以下の価値を提供することを目的としています:

1. **AI偏差値による科学的な予測**
   - 過去のレース成績を統計的に分析
   - 客観的な指標に基づく馬の評価
   - 人間の主観を排除した公平な予測

2. **データドリブンな競馬分析**
   - 枠順傾向スコア(馬番有利度)
   - 脚質パターン予測(前残り/差し/追い込み)
   - 過去対決成績の可視化

3. **無料で高品質な競馬情報の提供**
   - 全レース予測を無料で公開
   - 33本以上の詳細な分析記事
   - コース分析、騎手分析、レース戦略などの教育コンテンツ

4. **万馬券的中の記録と共有**
   - 過去7日間の高配当的中情報
   - 1万円以上の払戻し記録
   - SNSでの自動配信

---

## 1.3 主要機能

### 1.3.1 AI予測機能

- **AI偏差値**: 過去のレースタイムを分析し、正規化されたスコア(平均50、標準偏差10)で評価
- **印(◎○▲△☆)**: 上位5頭に自動的に印を付与
- **脚質パターン**: 序盤のポジション取りから走法(逃げ/先行/差し/追込)を予測
- **枠順傾向**: 統計的に有利な馬番を特定
- **対決成績**: 同じレースに出走したことがある馬同士の勝敗記録

### 1.3.2 データ可視化

- **枠番有利度グラフ**: 各コース・距離における馬番ごとの有利度をバーチャートで表示
- **脚質パターン図**: 1コーナー時点での予測位置を可視化
- **対決マトリクス**: 馬同士の過去成績を表形式で表示

### 1.3.3 コンテンツ管理

- **33本以上の記事**: コース攻略、騎手分析、レース戦略などの深堀り記事
- **検索機能**: 記事とレース予測の全文検索
- **FAQ**: よくある質問への回答
- **お問い合わせフォーム**: ユーザーサポート

### 1.3.4 SNS自動投稿

- **1日3回の自動投稿**:
  - 朝7時: 万馬券的中報告 + パフォーマンス + 本日の注目馬
  - 昼12時: 本日のレース一覧 + AIランキング
  - 夜20時: 明日の注目レース分析
- **OG画像の自動生成**: SNS投稿用のカスタムビジュアル
- **重複投稿防止**: コンテンツハッシュによる管理

## 1.6 システムの特徴

### 1.6.1 完全自動化

- **データ収集**: 毎日自動でnetkeiba.comからレース情報を取得
- **予測生成**: AI偏差値と各種指標を自動計算
- **結果取得**: レース終了後に自動で結果を収集
- **SNS投稿**: 1日3回、決まった時間に自動投稿

### 1.6.2 メモリ効率

- **バッチ処理**: 15レースごとに分割して処理(Render環境)
- **ガベージコレクション**: バッチ間でメモリを解放
- **接続プール制限**: データベース接続を最小限に抑える(本番環境で3接続)

### 1.6.3 スクレイピング対策

- **ランダム遅延**: 2.5〜5.0秒のランダムウェイト
- **User-Agentローテーション**: 複数のUser-Agentを切り替え
- **リトライロジック**: 指数バックオフによる再試行
- **セッション管理**: 適切なクリーンアップでメモリリーク防止

### 1.6.4 SEO最適化

- **構造化データ**: JSON-LD形式でメタデータを埋め込み
- **動的サイトマップ**: 全レースページのURLを自動生成
- **ISR(Incremental Static Regeneration)**: 5分ごとにページを再生成
- **モバイルファースト**: レスポンシブデザインで全デバイス対応

## 1.9 主要な統計情報

### データベース規模

- **テーブル数**: 10テーブル
- **主要エンティティ**: レース、馬、騎手、調教師、結果、予測
- **保持期間**: 過去1〜2年のレースデータ

### コンテンツ規模

- **分析記事**: 33本以上
- **対応レース**: JRA + NAR 全場全レース
- **予測頻度**: 毎日更新

### パフォーマンス

- **API応答時間**: 平均 < 500ms
- **ページ生成**: ISRで5分ごと
- **スクレイピング**: 1レースあたり2.5〜5.0秒
