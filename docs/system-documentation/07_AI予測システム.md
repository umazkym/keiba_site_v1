# 07. AI予測システム

## 7.1 予測システム概要

AI予測システムは、過去のレース成績を統計的に分析し、各馬の能力を数値化(偏差値)して評価するシステムです。

### 7.1.1 予測対象

- **中央競馬 (JRA)**: 全10場全レース
- **地方競馬 (NAR)**: 全場全レース

### 7.1.2 予測指標

1. **AI偏差値**: 過去成績から算出した総合評価 (平均50, 標準偏差10)
2. **印 (◎○▲△☆)**: 偏差値上位5頭に付与
3. **脚質パターン**: 序盤のポジション取り予測 (1-100スケール)
4. **枠番有利度**: 統計的に有利な馬番を特定
5. **対決成績**: 過去に対戦した馬同士の勝敗記録

## 7.3 AI偏差値計算アルゴリズム

### 7.3.1 処理フロー

```
1. 過去成績取得 (1年分)
   ↓
2. 各レースのパフォーマンススコア計算
   - タイム分析
   - コース・距離ごとの平均タイムとの比較
   ↓
3. 時間減衰適用 (半減期180日)
   ↓
4. 重み付き平均スコア計算
   ↓
5. レース内の全馬で偏差値計算
   - 平均50, 標準偏差10に正規化
   ↓
6. 印付与 (上位5頭)
```

### 7.3.2 パフォーマンススコア計算

**目的**: 各レースでの馬の走りを数値化

**実装**:
```python
def calculate_performance_score(
    finish_time_sec: float,
    avg_time_for_course: float,
    ground_condition: str,
    rank: str
) -> float:
    """
    パフォーマンススコアを計算

    Args:
        finish_time_sec: 走破タイム (秒)
        avg_time_for_course: そのコース・距離の平均タイム (秒)
        ground_condition: 馬場状態 ('良', '稍重', '重', '不良')
        rank: 着順

    Returns:
        パフォーマンススコア (高いほど良い)
    """
    # タイム差を計算
    time_diff = avg_time_for_course - finish_time_sec

    # 馬場補正 (重馬場は平均タイムが遅くなるため補正)
    condition_factor = {
        '良': 1.0,
        '稍重': 0.98,
        '重': 0.95,
        '不良': 0.90
    }.get(ground_condition, 1.0)

    adjusted_time_diff = time_diff / condition_factor

    # スコア計算 (タイム差を秒数からスコアに変換)
    # 平均より1秒速い = スコア+10
    score = adjusted_time_diff * 10

    # 着順補正 (上位着順にボーナス)
    if rank == '1':
        score += 15
    elif rank == '2':
        score += 10
    elif rank == '3':
        score += 5

    return score
```

**平均タイム取得**:
```python
def get_average_time_for_course(
    db: Session,
    venue_name: str,
    course_type: str,
    distance: int,
    lookback_days: int = 365
) -> float:
    """
    過去のレースから平均タイムを計算
    """
    cutoff_date = datetime.now() - timedelta(days=lookback_days)

    avg_time = db.query(func.avg(Result.finish_time_sec)).join(
        Race
    ).filter(
        Race.venue_name == venue_name,
        Race.course_type == course_type,
        Race.distance == distance,
        Race.race_date >= cutoff_date,
        Result.rank == '1'  # 1着馬のタイムのみ
    ).scalar()

    return avg_time or 100.0  # デフォルト値
```

### 7.3.3 時間減衰 (Time Decay)

**目的**: 最近の成績を重視し、古い成績の影響を減らす

**実装**:
```python
import numpy as np

def calculate_time_decay_weight(days_ago: int, half_life: int = 180) -> float:
    """
    指数減衰による重み計算

    Args:
        days_ago: 何日前のレースか
        half_life: 半減期 (日数)

    Returns:
        重み (0.0 〜 1.0)
    """
    # 指数減衰関数: w = 0.5^(days_ago / half_life)
    weight = np.power(0.5, days_ago / half_life)
    return weight

# 使用例
weights = []
scores = []

for past_result in past_results:
    days_ago = (today - past_result.race.race_date).days
    weight = calculate_time_decay_weight(days_ago, half_life=180)

    weights.append(weight)
    scores.append(past_result.performance_score)

# 重み付き平均
weighted_avg_score = np.average(scores, weights=weights)
```

**半減期180日の意味**:
- 180日前のレースは、今日のレースの半分の重要度
- 360日前のレースは、1/4の重要度

### 7.3.4 偏差値計算

**目的**: レース内の馬同士を相対評価

**実装**:
```python
def calculate_deviation_scores(performance_scores: List[float]) -> List[float]:
    """
    偏差値を計算 (平均50, 標準偏差10)

    Args:
        performance_scores: 各馬のパフォーマンススコア

    Returns:
        各馬の偏差値
    """
    scores = np.array(performance_scores)

    # 平均と標準偏差
    mean = np.mean(scores)
    std = np.std(scores)

    if std == 0:
        # 全馬同じスコアの場合
        return [50.0] * len(scores)

    # 偏差値 = 50 + 10 × (スコア - 平均) / 標準偏差
    deviation_scores = 50 + 10 * (scores - mean) / std

    return deviation_scores.tolist()

# 使用例
horse_scores = [75.3, 68.2, 82.1, 60.5, 71.8, ...]  # 各馬のスコア
deviation_scores = calculate_deviation_scores(horse_scores)
# → [48.2, 43.1, 56.7, 35.8, 46.9, ...]
```

### 7.3.5 印の付与

**実装**:
```python
def assign_marks(predictions: List[Dict]) -> List[Dict]:
    """
    偏差値上位5頭に印を付与

    Args:
        predictions: 各馬の予測データ (deviation_scoreを含む)

    Returns:
        印を追加した予測データ
    """
    # 偏差値でソート (降順)
    sorted_predictions = sorted(
        predictions,
        key=lambda x: x.get('deviation_score') or 0,
        reverse=True
    )

    marks = ['◎', '○', '▲', '△', '☆']

    for i, pred in enumerate(sorted_predictions):
        if i < 5 and pred.get('deviation_score'):
            pred['mark'] = marks[i]
        else:
            pred['mark'] = None

    return predictions
```

## 7.4 脚質パターン予測

### 7.4.1 目的

レース序盤(1コーナー時点)での予想位置を予測し、逃げ/先行/差し/追い込みの走法を判定

### 7.4.2 実装

```python
def calculate_start_position_indicator(
    past_results: List[Result]
) -> int:
    """
    脚質パターンを計算 (1-100スケール)

    1-30: 逃げ・先行
    31-70: 中団・差し
    71-100: 後方・追い込み

    Args:
        past_results: 過去のレース結果 (corner_positionsを含む)

    Returns:
        脚質パターン値 (1-100)
    """
    first_corner_positions = []

    for result in past_results:
        if result.corner_positions and '1' in result.corner_positions:
            pos = result.corner_positions['1']
            total_horses = result.race.total_horses

            # 相対位置 (0.0 〜 1.0)
            relative_pos = pos / total_horses if total_horses else 0.5

            first_corner_positions.append(relative_pos)

    if not first_corner_positions:
        return 50  # デフォルト (中団)

    # 平均相対位置
    avg_relative_pos = np.mean(first_corner_positions)

    # Zスコア計算
    std = np.std(first_corner_positions)
    if std > 0:
        z_score = (avg_relative_pos - 0.5) / std
    else:
        z_score = 0

    # 1-100スケールに変換
    # Zスコアを-3〜+3の範囲で1-100にマッピング
    indicator = int(50 + z_score * 16.67)
    indicator = max(1, min(100, indicator))  # 1-100にクリップ

    return indicator

# 使用例
past_results = get_horse_past_results(db, horse_id, limit=20)
start_indicator = calculate_start_position_indicator(past_results)
# start_indicator = 25 → 逃げ・先行タイプ
# start_indicator = 50 → 中団タイプ
# start_indicator = 80 → 追い込みタイプ
```

### 7.4.3 表示例

```
start_indicator = 25 → "━━━●━━━━━━" (前方)
start_indicator = 50 → "━━━━━●━━━━" (中団)
start_indicator = 80 → "━━━━━━━━●━" (後方)
```

## 7.5 枠番有利度計算

### 7.5.1 目的

統計的に有利な馬番を特定 (コース・距離ごと)

### 7.5.2 実装

```python
def calculate_horse_number_advantages(
    db: Session,
    venue_name: str,
    course_type: str,
    distance: int,
    lookback_days: int = 730
) -> List[Dict]:
    """
    枠番有利度を計算

    Args:
        db: DBセッション
        venue_name: 競馬場名
        course_type: 芝/ダート
        distance: 距離
        lookback_days: 過去何日分のデータを使用するか

    Returns:
        各馬番の有利度スコア
    """
    cutoff_date = datetime.now() - timedelta(days=lookback_days)

    # 過去のレース結果を取得
    results = db.query(Result).join(Race).filter(
        Race.venue_name == venue_name,
        Race.course_type == course_type,
        Race.distance == distance,
        Race.race_date >= cutoff_date
    ).all()

    # 馬番ごとの集計
    horse_number_stats = {}

    for result in results:
        num = result.horse_number
        if num not in horse_number_stats:
            horse_number_stats[num] = {'total': 0, 'top2': 0}

        horse_number_stats[num]['total'] += 1

        # 2着以内
        if result.rank in ['1', '2']:
            horse_number_stats[num]['top2'] += 1

    # 有利度スコア計算
    advantages = []

    for horse_number, stats in horse_number_stats.items():
        if stats['total'] < 10:
            # サンプル数不足
            continue

        # 実際の連対率
        actual_rate = stats['top2'] / stats['total']

        # 期待連対率 (ランダムの場合)
        avg_total_horses = 16  # 仮定
        expected_rate = 2.0 / avg_total_horses

        # 有利度スコア = (実際の連対率 - 期待連対率) × 100
        advantage_score = (actual_rate - expected_rate) * 100

        advantages.append({
            'horse_number': horse_number,
            'advantage_score': advantage_score,
            'sample_size': stats['total']
        })

    return advantages

# 使用例
advantages = calculate_horse_number_advantages(
    db, '東京', '芝', 1600
)
# [
#   {'horse_number': 1, 'advantage_score': -5.2, 'sample_size': 150},
#   {'horse_number': 2, 'advantage_score': +3.1, 'sample_size': 148},
#   ...
# ]
```

## 7.6 対決成績集計

### 7.6.1 目的

同じレースに出走する馬同士の過去対戦成績を集計

### 7.6.2 実装

```python
def calculate_matchups(
    db: Session,
    race_id: str,
    horse_ids: List[str]
) -> Dict:
    """
    対決成績を計算

    Args:
        db: DBセッション
        race_id: レースID
        horse_ids: 出走馬のIDリスト

    Returns:
        対決マトリクスデータ
    """
    matchups = {}

    # 全組み合わせを生成
    from itertools import combinations

    for horse1_id, horse2_id in combinations(horse_ids, 2):
        # 過去に両馬が出走したレースを検索
        past_races = db.query(Race.id).join(Result).filter(
            Result.horse_id == horse1_id
        ).intersect(
            db.query(Race.id).join(Result).filter(
                Result.horse_id == horse2_id
            )
        ).all()

        if not past_races:
            continue

        # 各レースの結果を集計
        horse1_wins = 0
        horse2_wins = 0
        draws = 0
        race_details = []

        for (race_id_tuple,) in past_races:
            result1 = db.query(Result).filter(
                Result.race_id == race_id_tuple,
                Result.horse_id == horse1_id
            ).first()

            result2 = db.query(Result).filter(
                Result.race_id == race_id_tuple,
                Result.horse_id == horse2_id
            ).first()

            rank1 = int(result1.rank) if result1.rank.isdigit() else 999
            rank2 = int(result2.rank) if result2.rank.isdigit() else 999

            if rank1 < rank2:
                horse1_wins += 1
            elif rank2 < rank1:
                horse2_wins += 1
            else:
                draws += 1

            race_details.append({
                'race_id': race_id_tuple,
                'race_name': result1.race.race_name,
                'race_date': result1.race.race_date.isoformat(),
                'venue_name': result1.race.venue_name,
                'distance': result1.race.distance,
                'course_type': result1.race.course_type,
                'horse1_rank': result1.rank,
                'horse2_rank': result2.rank,
                'horse1_time': result1.finish_time_sec,
                'horse2_time': result2.finish_time_sec
            })

        # 対決データを保存
        matchup_key = f"{horse1_id}_vs_{horse2_id}"
        matchups[matchup_key] = {
            'horse1_id': horse1_id,
            'horse1_name': db.query(Horse).get(horse1_id).name,
            'horse2_id': horse2_id,
            'horse2_name': db.query(Horse).get(horse2_id).name,
            'horse1_wins': horse1_wins,
            'horse2_wins': horse2_wins,
            'draws': draws,
            'races': race_details
        }

    return matchups
```

## 7.7 予測不可判定

### 7.7.1 予測不可条件

以下の場合、偏差値を計算せず「予測不可」とする:

1. **新馬戦**: 過去成績がない
2. **障害戦**: タイム比較が困難
3. **データ不足**: 過去5走未満
4. **転厩直後**: 調教環境の変化

### 7.7.2 実装

```python
def is_unpredictable(race_info: Dict, horse_data: Dict, past_results: List[Result]) -> str | None:
    """
    予測不可かどうかを判定

    Returns:
        予測不可理由 (予測可能な場合はNone)
    """
    # 新馬戦
    if '新馬' in race_info.get('race_name', ''):
        return '新馬戦のため予測不可'

    # 障害戦
    if '障害' in race_info.get('race_name', ''):
        return '障害戦のため予測不可'

    # データ不足
    if len(past_results) < 5:
        return f'過去成績不足 ({len(past_results)}走)'

    # その他の条件...

    return None  # 予測可能

# 使用例
unpredictable_reason = is_unpredictable(race_info, horse_data, past_results)

if unpredictable_reason:
    prediction = {
        'horse_id': horse_data['horse_id'],
        'horse_name': horse_data['horse_name'],
        'deviation_score': None,
        'mark': None,
        'unpredictable_reason': unpredictable_reason
    }
```

## 7.8 予測精度と検証

### 7.8.1 評価指標

1. **的中率**: AI◎の1着的中率
2. **連対率**: AI◎○の1-2着的中率
3. **回収率**: AI予測に基づく馬券購入の回収率

### 7.8.2 検証方法

```python
def evaluate_prediction_accuracy(db: Session, date_from: date, date_to: date) -> Dict:
    """
    予測精度を評価
    """
    # 対象期間の予測とレース結果を取得
    predictions = db.query(Prediction).join(Race).filter(
        Race.race_date >= date_from,
        Race.race_date <= date_to,
        Prediction.mark == '◎'
    ).all()

    total = len(predictions)
    first_place_count = 0
    top2_count = 0

    for pred in predictions:
        result = db.query(Result).filter(
            Result.race_id == pred.race_id,
            Result.horse_id == pred.horse_id
        ).first()

        if result:
            if result.rank == '1':
                first_place_count += 1
            if result.rank in ['1', '2']:
                top2_count += 1

    return {
        'total_predictions': total,
        'first_place_rate': first_place_count / total if total else 0,
        'top2_rate': top2_count / total if total else 0
    }

# 使用例
accuracy = evaluate_prediction_accuracy(db, date(2025, 1, 1), date(2025, 1, 31))
# {
#   'total_predictions': 450,
#   'first_place_rate': 0.28,  # 28%
#   'top2_rate': 0.52           # 52%
# }
```
