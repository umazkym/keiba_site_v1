## 運用原則

- 主要KPIは「AdSense収益 / 1,000人間セッション」。2026年6月22日〜7月21日の暫定基準は約392円。
- 終了判断日の9:00 JSTにCodexリマインドが登録されていない実験は開始しない。
- リマインドは判断を促すだけとし、広告設定を自動終了・自動変更しない。
- 原案とバリエーションのどちらを採用する場合も、終了操作と採用設定の反映を同時に行い、広告が無効な中間状態を作らない。
- 単日の推定収益では判断せず、前日までの確定値と同曜日構成を使う。

### 採用条件

- 対象セッション1,000件当たり収益が原案より5%以上高い。
- `prediction_table_view`と`race_navigation`の低下が各10%未満。
- Clarityのデッドクリック率とクイックバック率の悪化が各2ポイント未満。
- モバイルCLSが0.1以下。
- ポリシー警告、広告重複、主要操作の阻害がない。

### 延長・復元条件

- 1,000表示未満または計測不良なら終了せず7日延長し、リマインドも同時に更新する。
- 原則として7日間かつ対象レースセッション500件を満たすまで早期終了しない。
- 上記を満たした後、対象セッション1,000件当たり収益が原案より15%以上低く、同曜日構成のサイト全体収益も低下し、`prediction_table_view`または`race_navigation`が10%以上低下し、欠損や計測不良で説明できない場合は原案へ戻す。
- 収益差が±5%以内、指標が相反する、または最低サンプル未達の場合は勝敗不明として7日延長する。
- ポリシー警告、広範な未配信、解除不能なOfferwall、主要操作の阻害、重大なCLSやJavaScript障害はサンプルを待たずに原案へ戻す。
