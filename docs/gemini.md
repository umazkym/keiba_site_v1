# Gemini Interaction Guidelines

このファイルは、AIエージェント（Gemini）がユーザー（zk-ht）と対話・開発を行う際の指針と、プロジェクトの構造をまとめたものです。

## 基本指針

1.  **言語**: 全て日本語で対話を行ってください。
2.  **思考プロセス**:
    *   時間がかかっても構わないので、深く推論を行ってください。
    *   表面的な解決策ではなく、根本的な原因を特定し、恒久的な解決策を提案してください。
    *   「その場しのぎ」の修正は禁止です。
3.  **不確実性への対処**:
    *   不明点や自信のない点は、勝手に判断せずユーザーに質問してください。
    *   または、デバッグコードを挿入したり、現状を確認するコマンドを実行したりして、事実に基づいて判断してください。
4.  **ディレクトリ構造の把握**:
    *   プロジェクトの構造を常に正確に把握し、適当なパスや構造を仮定しないでください。

## プロジェクト構造 (keiba_site_v1)

このプロジェクトは、競馬予想サイトの構築プロジェクトです。
ルートディレクトリ: `C:\Users\zk-ht\Keiba\keiba_site_v1`

### ディレクトリ構成概要

*   **backend/**: Pythonによるバックエンド・データ処理系
    *   `api/`: APIエンドポイント（FastAPI等）
    *   `core/`: コアロジック
    *   `crud/`: データベース操作
    *   `database/`: DB接続設定
    *   `schemas/`: Pydanticモデル
    *   `scripts/`: ユーティリティスクリプト
    *   `db_handler.py`: データベースハンドリングの主要モジュール
    *   `run_pipeline.py`: データ収集・分析パイプラインの実行スクリプト
    *   `selenium_config.py`: スクレイピング用のSelenium設定
    *   `generate_race_graphs.py`: グラフ生成ロジック
    *   `generate_website_analysis_data.py`: Webサイト用分析データ生成
*   **frontend/**: Next.jsによるフロントエンド
    *   `app/`: Next.js App Routerのページ・レイアウト
    *   `components/`: Reactコンポーネント
    *   `lib/`: ユーティリティ関数、型定義
    *   `styles/`: グローバルスタイル、Tailwind設定
    *   `public/`: 静的ファイル
*   **docs/**: ドキュメント (本ファイルを含む)
*   **data/**: データ保存用ディレクトリ
*   **analysis_results/**: 分析結果の出力先
*   **debug_html/**: デバッグ用に保存されたHTMLファイル
*   **sns_images_dist/**: SNS用画像の出力先

### 開発ワークフローの注意点

*   **バックエンド**: Pythonスクリプトは主にデータ収集（スクレイピング）、分析、DB格納を行います。`run_pipeline.py` が中核となることが多いです。
*   **フロントエンド**: Next.js + Tailwind CSSを使用。UI/UXの改善（リッチなデザイン、アニメーション）が重視されています。
*   **データ連携**: バックエンドで生成・整形されたデータを、フロントエンドが表示する構成です。

*   構造に変更があった場合は、このファイルを更新して常に最新の状態に保ってください。
