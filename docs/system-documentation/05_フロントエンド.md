### 5.3.1 PredictionTable (予測テーブル)

**場所**: `components/race/PredictionTable.tsx`

**役割**: AI予測データを表形式で表示

**Props**:
```typescript
interface PredictionTableProps {
  predictions: Prediction[];
  raceInfo: {
    course_type: string;
    distance: number;
    venue_name: string;
  };
}
```

**表示内容**:
- 馬番
- 印 (◎○▲△☆)
- 馬名
- AI偏差値
- 脚質パターン (1コーナー位置)
- 枠順有利度
- オッズ / 人気 (レース前は未表示)

**機能**:
- 偏差値順にソート
- 予測不可馬は下部に表示
- レスポンシブデザイン (モバイル対応)

**実装例**:
```tsx
export default function PredictionTable({ predictions, raceInfo }: Props) {
  // 偏差値でソート
  const sorted = [...predictions].sort((a, b) =>
    (b.deviation_score ?? 0) - (a.deviation_score ?? 0)
  );

  return (
    <div className="overflow-x-auto">
      <table className="min-w-full divide-y divide-gray-200">
        <thead className="bg-gray-50">
          <tr>
            <th>馬番</th>
            <th>印</th>
            <th>馬名</th>
            <th>AI偏差値</th>
            <th>脚質</th>
            <th>枠有利</th>
          </tr>
        </thead>
        <tbody>
          {sorted.map((pred) => (
            <tr key={pred.horse_id}>
              <td className="text-center">{pred.horse_number}</td>
              <td className="text-center text-2xl">{pred.mark}</td>
              <td className="font-semibold">{pred.horse_name}</td>
              <td className="text-center">
                {pred.deviation_score?.toFixed(1) ?? '-'}
              </td>
              <td className="text-center">
                <StartIndicator value={pred.start_1c_indicator} />
              </td>
              <td className="text-center">
                {/* 枠有利度表示 */}
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}
```

### 5.3.2 HorseNumberAdvantageChart (枠番有利度グラフ)

**場所**: `components/race/HorseNumberAdvantageChart.tsx`

**役割**: 馬番ごとの統計的有利度をバーチャートで可視化

**Props**:
```typescript
interface ChartProps {
  advantages: HorseNumberAdvantage[];
  maxHorseNumber: number;
}
```

**使用ライブラリ**: Chart.js

**実装例**:
```tsx
import { Bar } from 'react-chartjs-2';

export default function HorseNumberAdvantageChart({ advantages }: Props) {
  const data = {
    labels: advantages.map(a => a.horse_number),
    datasets: [{
      label: '有利度スコア',
      data: advantages.map(a => a.advantage_score),
      backgroundColor: advantages.map(a =>
        a.advantage_score > 0 ? 'rgba(34, 197, 94, 0.6)' : 'rgba(239, 68, 68, 0.6)'
      ),
      borderColor: advantages.map(a =>
        a.advantage_score > 0 ? 'rgb(34, 197, 94)' : 'rgb(239, 68, 68)'
      ),
      borderWidth: 1
    }]
  };

  const options = {
    responsive: true,
    plugins: {
      legend: { display: false },
      title: {
        display: true,
        text: '枠番有利度 (統計データ)'
      }
    },
    scales: {
      y: {
        beginAtZero: true,
        title: { display: true, text: 'スコア' }
      },
      x: {
        title: { display: true, text: '馬番' }
      }
    }
  };

  return <Bar data={data} options={options} />;
}
```

### 5.3.5 RaceSelector (レース選択)

**場所**: `components/race/RaceSelector.tsx`

**役割**: 日付選択と競馬場選択

**機能**:
- カレンダー形式の日付選択
- 前日/翌日ボタン
- 競馬場ドロップダウン

**実装**:
```tsx
export default function RaceSelector({ currentDate, onDateChange }: Props) {
  const navigate = useRouter();

  const handlePrevDay = () => {
    const prev = addDays(parseISO(currentDate), -1);
    navigate.push(`/races/${format(prev, 'yyyy-MM-dd')}`);
  };

  const handleNextDay = () => {
    const next = addDays(parseISO(currentDate), 1);
    navigate.push(`/races/${format(next, 'yyyy-MM-dd')}`);
  };

  return (
    <div className="flex items-center gap-4">
      <button onClick={handlePrevDay}>前日</button>
      <input
        type="date"
        value={currentDate}
        onChange={(e) => navigate.push(`/races/${e.target.value}`)}
      />
      <button onClick={handleNextDay}>翌日</button>
    </div>
  );
}
```

### 5.4.2 レースページ (app/races/[date]/page.tsx)

**役割**: 指定日のレース予測表示

**Dynamic Routing**: `/races/2025-01-15`

**Static Params生成**:
```tsx
export async function generateStaticParams() {
  const dates = [];

  // 過去30日〜未来14日のページを事前生成
  for (let i = -30; i <= 14; i++) {
    const date = addDays(new Date(), i);
    dates.push({
      date: format(date, 'yyyy-MM-dd')
    });
  }

  return dates;
}
```

### 5.4.3 記事ページ (app/articles/[slug]/page.tsx)

**役割**: Markdown記事の表示

**データ取得**:
```tsx
import fs from 'fs';
import path from 'path';
import matter from 'gray-matter';

export default async function ArticlePage({ params }: { params: { slug: string } }) {
  const filePath = path.join(process.cwd(), 'content/articles', `${params.slug}.md`);
  const fileContents = fs.readFileSync(filePath, 'utf8');
  const { data, content } = matter(fileContents);

  return (
    <article className="prose lg:prose-xl mx-auto">
      <h1>{data.title}</h1>
      <p className="text-gray-500">{data.date}</p>

      <ReactMarkdown
        remarkPlugins={[remarkGfm]}
        components={{
          h2: ({ node, ...props }) => <h2 className="text-3xl mt-8" {...props} />,
          // カスタムレンダリング
        }}
      >
        {content}
      </ReactMarkdown>

      <RelatedArticles currentSlug={params.slug} category={data.category} />
    </article>
  );
}
```

**Static Params**:
```tsx
export async function generateStaticParams() {
  const articlesDir = path.join(process.cwd(), 'content/articles');
  const files = fs.readdirSync(articlesDir);

  return files
    .filter(file => file.endsWith('.md'))
    .map(file => ({
      slug: file.replace('.md', '')
    }));
}
```
