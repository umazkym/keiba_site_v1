## 本番反映日Rの作業

### 環境値

```text
NEXT_PUBLIC_RACE_REVENUE_EXPERIMENT_MODE=legacy
NEXT_PUBLIC_RACE_ENGAGED_AD_SLOT=7550236816
NEXT_PUBLIC_ANALYTICS_RELEASE_ID=2026-08-01-ga-route-v2
```

`NEXT_PUBLIC_RACE_REVENUE_EXPERIMENT_MODE`は次の3値だけを使用する。

| 値 | 動作 |
| --- | --- |
| `legacy` | 既存レース末尾`infeed-content`だけを表示。既定値・即時復元値 |
| `split` | 1023px以下の利用者をタブセッション固定50/50で割り当て |
| `engaged_display` | 1023px以下へ新枠を100%適用。採用決定後だけ使用 |

### DebugViewとローカル確認

1. 初回表示で`page_view`が1回、`race_view`が1回送られる。
2. Next.jsの通常ページ遷移先で`page_view`が1回送られる。
3. レース番号・競馬場切替の`history.replaceState`では`page_view`が0回で、`race_view`だけが送られる。
4. `ad_experiment_exposure`、`ad_impression_custom`、`ad_viewable_custom`に実験ID、variant、配置、slot IDが付く。
5. `legacy`と`engaged_display`のどちらも1ページに配信済み広告が最大1枠である。
6. 未配信が画面内へ入る前に確定した場合だけ枠を畳み、表示中は250pxの予約領域を維持する。
7. 375、390、768、1024、1440pxで広告重複、横はみ出し、予想表・レース選択・sticky UIとの接触がない。
8. `sitemap-data.xml`をSearch Consoleで再読込し、404、canonical、リダイレクトエラーを確認する。

## 開始日時Dの条件

- `measurement_release_id=2026-08-01-ga-route-v2`だけを対象に、高速ゲート（3完全日・主要欠損と`Unassigned`が各2%未満・合計500セッション）または標準ゲート（7完全日・各5%未満）を通過。
- モバイルp75がLCP 2.5秒以下、INP 200ms以下、CLS 0.1以下。
- AdSenseユニット`race-engaged-display-v1`とslot `7550236816`が環境値に設定済み。
- `legacy`と`engaged_display`のローカルプレースホルダー、配信済み、未配信、会場切替、日付切替を確認済み。
- D+7 09:00とD+14 09:00のCodexリマインドを作成し、IDを台帳へ記録済み。

条件が1つでも欠ける場合は`legacy`を維持する。リマインド作成前に`split`へ切り替えない。

## D+7とD+14の採否

D+7は各群500モバイル人間セッション以上を条件とする中間判断で、収益差が±15%以上かつ保護指標も同方向の場合だけ早期採用または停止を検討する。差が小さい、母数不足、指標が競合する場合はD+14まで継続する。D+14は各群1,000セッション以上を最終条件とし、結論が不明確な場合は新配置を恒久採用せず`legacy`へ復元する。

バリエーションは次のすべてを満たした場合だけ採用する。

1. 対象広告収益/1,000割当セッションが原案より10%以上高い。
2. Active Viewが55%以上。
3. 収益差の95%ブートストラップ信頼区間下限が-5%を上回る。
4. `prediction_table_view`と`race_navigation`が5%以上低下しない。
5. クイックバックが2ポイント以上悪化しない。
6. モバイルCLSが0.1以下、INPが200ms以下。

3日連続で主要操作が10%以上低下、CLSが0.15超、広告重複、ポリシー警告のいずれかが発生した場合はサンプルを待たず`legacy`へ戻す。
