# GA4・AdSense連携と広告収益最大化のための設定方針

## 1. 目的と概要
本ドキュメントは、KeibaAI_v2プロジェクトにおける広告収益（AdSense / リワード広告等）を最大化するため、Google Analytics 4 (GA4) で行うべき連携、カスタムイベント、カスタムディメンションの設定、および分析手法を定義する。
ユーザーの行動と広告収益を紐づけ、「推測」ではなく「データに基づいた」UI/UXの改善とコンテンツ戦略を可能にすることを目的とする。

## 2. 必須設定項目：AdSense / アドマネージャーとGA4の連携
何よりもまず、広告の収益データを直接GA4に取り込むための連携が必要となる。

* **設定手順**:
  1. AdSenseの管理画面から「アカウント」 ＞ 「アクセスと認証」 ＞ 「Google アナリティクス リンクの管理」へアクセスする。
  2. 該当のGA4プロパティを選択しリンクを作成する。
* **期待される効果**:
  GA4の「レポート」＞「収益化」＞「パブリッシャー広告」メニューがアクティブになり、ページごと、広告フォーマットごとの収益データ（インプレッション、クリック、パブリッシャー広告収益）が確認可能になる。

## 3. 分析を深めるための「カスタムイベント」と「パラメータ」実装
GA4の標準イベント（`page_view`, `scroll`等）だけでは、競馬サイト特有のユーザー行動と広告収益の細かい相関関係が見えにくい。
以下のイベントをGoogleタグマネージャー（GTM）または直接のJSタグ実装で追加取得することを推奨する。

### 3.1 推奨カスタムイベント一覧
| イベント名 (推奨) | トリガー条件 | 目的・分析用途 |
| :--- | :--- | :--- |
| `read_complete` | 記事の最下部（予想印エリアやAI解説など）までスクロール、かつ一定時間滞在した時 | ユーザーの熟読度と広告クリック率の相関関係分析 |
| `prediction_view` | 「AI予想結果（有料・リワード）」を閲覧した時 | アンロック後のエンゲージメント確認、リワード視聴効果の比較 |
| `ad_impression_custom` | 記事内・フローティング等の重要広告が画面内に表示された時 | 広告ユニットごとの視認性（Viewability）と貢献度の個別計測 |
| `sns_share` | 各種SNSのシェアボタン押下時 | ソーシャル流入を生み出すユーザーと広告収益のLTV確認 |

### 3.2 必須となるカスタムディメンション
カスタムイベントで取得した値を分析の「軸」として利用するために、GA4の管理画面（「設定」 ＞ 「カスタム定義」）で以下をカスタムディメンションとして登録する。

| パラメータ名 | スコープ | 説明 (値の例) | 収益最大化における活用方法 |
| :--- | :--- | :--- | :--- |
| `content_category` | イベント | 記事カテゴリ（e.g., `race_prediction`, `data_analysis`, `news`） | どのカテゴリの記事が最もユーザーあたりの広告収益(ARPU)が高いかを特定 |
| `ad_placement` | イベント | 広告の位置（e.g., `header`, `in_article_1`, `sticky_bottom`） | 広告配置別の収益性・クリック率の比較により、レイアウトを最適化 |
| `predict_accuracy` | イベント | 予想の的中フラグ (e.g., `hit`, `miss`) | 「的中したレース記事」の検証による再訪率上昇と、それに伴う広告収益への影響確認 |

## 4. 収益最大化のための分析・活用フレームワーク
データが蓄積され始めたら、GA4の「探索（Exploration）」機能を用いて以下の観点で分析を行い、サイト改善のPDCAを回す。

### ① 高収益コンテンツの特定と増産
* **使用する軸**: ページパス、`content_category` (カスタムディメンション)
* **指標**: パブリッシャー広告収益、ユーザーあたりの広告収益
* **具体的なアクション**: 収益性の高いカテゴリ（例：特定の重賞レース予想、穴馬データ）を特定し、AIによる記事生成リソースをそのジャンルに集中させる。

### ② 広告の「視認位置」と「ユーザー行動」の相関検証
* **使用する軸**: スクロール深度（`scroll`）、`read_complete` の有無
* **指標**: 広告クリック数、パブリッシャー広告収益
* **具体的なアクション**: ユーザーの離脱が急増する箇所の直前、または熟読される箇所（推奨馬の表のすぐ下など）へ広告を移動し、インプレッションの価値を高める。

### ③ 流入元（チャネル）別の収益性評価 (ROAS的視点)
* **使用する軸**: セッションの参照元 / メディア
* **指標**: セッションあたりの広告収益、直帰率
* **具体的なアクション**: SEO、SNS（X連携等）のうち、どの流入元が最も収益への貢献度が高いかを判断し、集客の注力ポイントを調整する。

## 5. 実装に向けたネクストステップ
1. **[運用連携]** AdSenseアカウントと該当GA4プロパティのリンク（※ユーザー自身による管理画面での設定が必要）
2. **[開発]** フロントエンド（`app/` / `components/`等）へのGTMないしはGA4タグの実装。および推奨カスタムイベントの発火ロジック追加。
3. **[設定]** GA4管理画面での「カスタムディメンション」の登録。
4. **[分析]** 上記の実装完了後、2週間〜1ヶ月程度のデータを蓄積し「探索」レポートを作成、最適化施策の第一弾を立案する。
