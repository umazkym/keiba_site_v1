# 広告収益化戦略とレイアウト安全性基準（2026年3月）

## 概要
UMA-FREE（uma-free.com）における広告収益化について、再検証・深層推論を行った結果の戦略と、AdSenseポリシーに準拠するためのレイアウト基準を定めたドキュメント。

## 分析結果の訂正と真の課題
当初は「記事内広告の不足」「PC両サイドの未活用」が課題かと思われたが、ソースコードと表示幅の計算を深く精査した結果、以下の事実が判明した。

1. **PCサイドバー追従広告（StickyAd）のオーバーラップ問題（致命的）**
   - メインコンテンツ幅が `max-w-[1600px]` と広大であるのに対し、`StickyAd` が `1280px` 以上の画面で右端固定（`fixed`）で表示される実装になっている。
   - これにより、1280px〜1600px幅のモニター環境において、**追従広告がメインコンテンツ（データ表など）の上に重なって覆い隠してしまう**状態が発生しやすい。
   - これは、UXの著しい低下のみならず、Google AdSenseの「コンテンツの隠ぺい」ポリシー違反となり、アカウント停止（垢BAN）や広告配信停止の直接的な原因となる重大なリスクである。

2. **インフィード広告の密度（現状で最適）**
   - `RaceTabs.tsx` 内には既に適切な間隔で3つの `AdUnit` が配置されている。
   - これ以上広告を詰め込むと、情報量と広告量のバランスが崩れ、SEOおよびAdSense評価の低下を招く。現状が「最適解」である。

## 今後の戦略（アクションプラン）
最大の収益化とは、単に広告を増やすことではなく、「ポリシー違反による配信停止リスクをゼロにすること」と「ユーザーの閲覧体験を妨げないこと」の両立である。

### 1. StickyAd の安全化改修（直近のタスク）
- `StickyAd.tsx` の表示条件を厳格化する。
- メインコンテンツ幅の最大値と、広告幅（300px）、およびパディングを計算し、**「絶対にメインコンテンツと被らない画面幅（例：1600px + 余白、もしくは動的なマージン計算）」**が確保された場合にのみ表示・追従するようロジックとCSS（Tailwind）を改修する。

### 2. モバイル自動広告の位置最適化（管理画面）
- AdSense側の「自動アンカー広告」設定を、ページ上部から「ページ下部」へ変更する。
- ヘッダーナビゲーションへの干渉を防ぎ、誤クリックによるペナルティリスクを排除する。
