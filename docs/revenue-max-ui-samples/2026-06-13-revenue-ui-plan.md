# UMA-FREE 広告収益最大化に向けた自然化案

作成日: 2026-06-13

この案は、第三者提案をそのまま採用するのではなく、現在のUMA-FREEの良さである「白基調の信頼感」「データサイトらしい静かな見せ方」「広告を押し込みすぎない導線」を残したうえで、広告表示機会と回遊量を増やす方向に整理したものです。

## 残すべき方向性

- 現行の白・スレート・青を中心にした落ち着いたUIを維持する。
- 黒基調、強い赤いCTA、絵文字多用は避ける。
- 「投資」「必勝」「絶対」「最強」「消し」などの強い表現は使わない。
- レースページでは、AI偏差値一覧に早く到達できる状態を優先する。
- 広告はCLSを起こさない予約枠を維持し、PR表記と `rel="sponsored nofollow noopener noreferrer"` を前提にする。
- JRAレースに地方競馬投票サービスの文言を出すような不自然な出し分けは避ける。

## ホーム改善案

### 1. 上部の再訪導線を強化

`RecentRaceReturn` をヘッダー直下に近い位置へ移動し、履歴があるユーザーには最大3件の「最近確認したレース」を横並びで表示する。履歴がない場合は「本日の注目レース」または「本日の分析へ」を表示する。

狙い:

- 再訪ユーザーが目的のレースへ戻るまでのスクロール量を減らす。
- レースページ再訪が増え、自然に広告接触回数も増える。

### 2. ヒーローは具体化しつつ圧縮

現在の「今日のレース分析を無料で確認」は抽象度が高いため、当日の開催場と総レース数を入れる。

例:

- `函館・東京・阪神 全58レース分析公開中`
- `展開予測・対戦成績・枠順傾向をひと目で確認`
- `本日 07:05 更新済`

ただしヒーローを大きくしすぎず、モバイルではファーストビュー内に「最近見たレース」「ヒーロー」「重賞カードの一部」まで見える高さを目標にする。

### 3. 本日の開催を情報付きチップへ

会場名だけでなく、`全12R`、`9R進行中`、`結果反映` のような短い状態を追加する。過度なLIVE演出ではなく、点と小さなバッジ程度に抑える。

### 4. 今週の重賞はG1のみ格上げ

すべてを大きくするとページが重くなるため、G1だけをフル幅または強調カードにする。G2/G3は現状に近いコンパクトチップを維持する。

### 5. 広告配置

上部の大型広告を増やすより、ユーザーが一段読み終えた場所へ置く。

- ヒーロー直下の大型広告は採用しない。
- 本日の開催直後に小さめの横長広告を1枠置く。
- 高配当的中ランキング直後に300x250相当の広告を1枠置く。
- 今日の分析注目馬の中または直後に、NAR文脈では楽天競馬、その他では物販またはAdSenseを自然に出し分ける。
- 記事一覧4枚目のネイティブ広告は現状方針を維持する。
- 記事一覧直後またはFAQ直前に大型広告を1枠置く。
- モバイル追従広告はスクロール15%以降に遅延表示する。

## レース詳細改善案

### 1. 上部固定バーに最小限のレース要約を追加

日付ピッカーだけでなく、現在表示中のレースとAI上位評価を1行で確認できるようにする。

例:

- `2026年6月13日（土） 函館9R 奥尻特別`
- `◎ ドゥアドバンテージ 62.4`

### 2. レース間ナビを表の上にも置く

予想表の下だけでなく、上にも `前のレース` / `次のレース` を置く。複数レースを巡回するユーザーが表を見る前後どちらでも移動できるため、ページビューと広告接触の両方が増えやすい。

### 3. 予想表に凡例と脚質バッジを追加

表の上に `◎本命 〇対抗 ▲3番手 △評価を上げたい条件 ☆注目` のような短い凡例を置く。馬名横または右端に `先行` `中団` `後方` などの位置取りバッジを追加する。

### 4. 広告は表の途中ではなく読了直後へ

PredictionTable内の広告撤去方針は維持し、AI偏差値一覧を読み終えた直後に広告を置く。展開/枠順グラフ後にも1枠置くが、各ブロックの途中には入れない。

### 5. AIレース展望は折りたたみ

冒頭2行だけ表示し、詳細は「続きを読む」で展開する。ファーストビューの情報密度を保ちつつ、読みたいユーザーには本文を残す。

## 採用しない方がよい点

- ホーム全体を黒基調に寄せること。
- JRAレースで「楽天競馬で馬券購入」のように誤解を招く文言を出すこと。
- 414x414の大型広告を上部に連続配置すること。
- 「穴馬発見」など、期待を強く煽るコピーを主見出しに使うこと。
- 記事カードのサムネイルを色違いだけで大量生成し、AI生成感を強めること。

## 実装優先度

1. レースページの表上ナビ、凡例、読了直後広告位置の整理。
2. ホームの最近見たレース最大3件化とヒーロー文言の具体化。
3. 本日の開催チップにレース数・状態を追加。
4. G1重賞カードの格上げ。
5. 今日の注目馬を3分類化し、NAR/物販/AdSenseの出し分けを検証。
